# AI-Python
 Medical Data Analysis Using AI (Python)  This project applies machine learning techniques to analyze a medical dataset obtained from Kaggle. The goal is to explore the data, identify patterns, and build predictive models for medical outcomes.
 Here is the description for **Project 1** only, ready to copy:



**Techniques Used:**
- K-Nearest Neighbors (KNN)
- Logistic Regression
- Linear Regression
- Naive Bayes

**Tools and Technologies:**
- Python (Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn)
- Jupyter Notebook
- Excel (for data storage and initial exploration)
- PowerPoint (for presenting results and insights)

**Project Components:**
- Python script for data preprocessing, model training, and evaluation.
- PowerPoint presentation summarizing methodology, results, and conclusions.
- Dataset (Excel format).

**Objective:**
To compare the performance of multiple machine learning algorithms on medical data and identify the most effective model for prediction.
